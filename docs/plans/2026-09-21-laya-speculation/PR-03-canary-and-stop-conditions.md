# PR-03 — 제한 적용과 실제 효과 판정

상태: 미구현. PR-02 안전성 검증 후. 제안 브랜치 `perf/laya-speculation-canary`.

처음에는 500별 이상 설치형 후보 중 안정적인 해시 표본 5%에만 허용한다. 모집단 전체에 같은 기본 심사를 유지하고, 동시성 상한/여유 슬롯 조건은 PR-02와 같다. kill switch 기본 off. 해당 값은 초기 제안이며 실제 여유 용량보다 앞서 활성화하지 않는다.

대조군과 처리군에서 순수 모델 시간, 준비·큐 시간, 1차→2차 완료, 전체 발행 시간, 실패율, 정상 후보 처리량, 추가 모델 호출 수를 분리한다. 적체 정도/원문 길이/모델 구성이 다른 집단의 단순 평균을 비교하지 않는다. 충분한 실제 후보가 없으면 기간을 늘린다.

관찰 시작 최소 조건은 각 집단 100건 및 30분이며, 이 수치만으로 통계적 신뢰나 오탐 0을 보장하지 않는다. 표본/변동성이 부족하면 결론 유보. 목표는 두 심사를 그대로 수행하면서 처리군의 전체 p50/p95가 대조군보다 낮고, 정상 처리량/실패율이 악화되지 않는 것이다. 이득이 없으면 off로 돌아간다.

즉시 중단: 승인 관문 우회, 오래된 원문 채택, 중복 발행, 수동 결정 덮기, 활성 호출 상한 초과. 성능 중단: 정상 큐 지연/실패/429 증가, 선행 결과 대부분 폐기, 비선행 대조군의 처리량 하락. 중단은 LAYA 및 선행 계산만 끄고 기존 심사는 계속한다. 이력이나 후보를 대량 삭제·재심사하지 않는다.

최종 보고는 실제 전체 지연 변화와 추가 호출 비용을 함께 낸다. LAYA 자체 응답 시간이나 이론상 겹침 시간을 실제 절감 시간으로 보고하지 않는다.
