## 같은 모델의 판단을 독립 표로 세지 않는다

1차가 이미 Sonnet인 후보에서 Sonnet 대체 결과는 **참고 의견**이다. 이 경우 2차 결과가 정상이어도 후보는 **사람 확인**으로 보낸다. 다른 모델의 찬성이 하나 더 있어도 자동 합의로 올리지 않는다. 대체 결과가 아직 없으면 계속 대기 중으로 집계한다. 규칙만 통과해 공개된 표본처럼 1차 AI 모델이 없는 경우에는 기존의 독립 모델 합의 규칙을 사용한다.

실제 대체 모델·원래 오류·연결 이력을 보존하고, 대체 호출을 포함해 누적 3회 실패하면 자동 호출을 끝낸다. 설정에서 대체 모델을 제거해 빈 심사 단계가 생긴 경우에도 후보를 사람 확인으로 남긴다. 제거된 의견을 빼면서 해당 단계를 집계에서 지워 버리지 않는다. 실패 횟수도 초기화하지 않는다.
