   lint job에 묶인 배포·Oracle·DR Python 검사6개는 별도 운영 검사 job으로 옮겨 해당 코드·DB/DR·CI 변경 시 필수로 선택할 수 있다. 검사 삭제가 목적은 아니며, 최신 lint 전체가52초라 이 분리만으로 큰 시간 절감을 약속하지 않는다. 통합 테스트는 이미 시간 가중 6분할이고 `integration-ledger`의19개 파일은 빈 DB·복원된 행 기준에 의존한다. 이 묶음의 순서나 직렬 실행을 무작정 풀지 않는다.

PR 이미지 사전 빌드는 `check`의 필수 job이 아니며 실패하면 main 빌드로 복귀한다. `refresh-caches`는 배포와 이미지가 기다리지 않는 보조 job이다. 전체 workflow 종료를 일괄 기다리지 않는다. 15분·6시간 관측은 별도 실제 시각에 실행하고, 예약만 된 관측은 미완료로 남긴다.
