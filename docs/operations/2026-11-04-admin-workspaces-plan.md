## 데이터와 제어의 계약

- 시안의 가상 프로젝트·모델·랜덤 수치·타이머 기반 진행을 실제 앱에 가져오지 않는다. 기존 서버 loader와 원본 상태를 재사용한다.
- 로컬 개발 DB는 최초 확인 시 제품·후보가 모두 0건이었다. 이를 운영 실데이터라고 표시하지 않는다. 운영 원본의 제한된 읽기 조회와 실제 화면 확인 결과를 별도로 기록한다.
- 조회 실패·오래된 관측·빈 결과를 구분하고, 관측하지 못한 모델 실행 수를 만들지 않는다. 서버 관측 시각과 화면 갱신 시각을 함께 해석한다.
- 기존 전역 수집 관문은 수집·심사·소개·분류/발행·발행분 감사에 영향을 준다. 개별 잡 제어, AI2 소비자 서비스, 모델 OPEN/DRAIN, 원본 공급은 같은 동작이 아니다.
- 2차 표·후보·모델 호출·공개 프로젝트·후처리 작업의 수치를 합산하지 않는다. 공개 후 번역·검색 완료는 공개 성공과 별도다.
- 인증·허용 목록·ingress·CSRF·원본 버전·감사 로그·DR fence를 유지한다. 개발 검증을 위해 운영 보호를 끄거나 실제 제어를 실행하지 않는다.
- 화면 상단의 장식 제목·소개문은 제거하되, 스크린리더 이름과 프로젝트 정체성, 경보·판단 근거·조치 버튼은 유지한다.
