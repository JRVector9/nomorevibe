## 데이터와 제어의 계약

- 시안의 가상 프로젝트·모델·랜덤 수치·타이머 기반 진행을 실제 앱에 가져오지 않는다. 기존 서버 loader와 원본 상태를 재사용한다.
- 로컬 개발 DB는 최초 확인 시 제품·후보가 모두 0건이었다. 이를 운영 실데이터라고 표시하지 않는다. 운영 원본의 제한된 읽기 조회와 실제 화면 확인 결과를 별도로 기록한다.
- 조회 실패·오래된 관측·빈 결과를 구분하고, 관측하지 못한 모델 실행 수를 만들지 않는다. 서버 관측 시각과 화면 갱신 시각을 함께 해석한다.
- 기존 전역 수집 관문은 수집·심사·소개·분류/발행·발행분 감사에 영향을 준다. 개별 잡 제어, AI2 소비자 서비스, 모델 OPEN/DRAIN, 원본 공급은 같은 동작이 아니다.
- 2차 표·후보·모델 호출·공개 프로젝트·후처리 작업의 수치를 합산하지 않는다. 공개 후 번역·검색 완료는 공개 성공과 별도다.
- 인증·허용 목록·ingress·CSRF·원본 버전·감사 로그·DR fence를 유지한다. 개발 검증을 위해 운영 보호를 끄거나 실제 제어를 실행하지 않는다.
- 화면 상단의 장식 제목·소개문은 제거하되, 스크린리더 이름과 프로젝트 정체성, 경보·판단 근거·조치 버튼은 유지한다.

이번 사용자 지시는 확정된 시안·실데이터·작업 흐름을 유지하면서 메뉴와 본문 글자를 각각 2 CSS px 키우고 상태 주석의 크기를 유지하는 후속 작업이다. 위 구현·검증 기록과 구분하며, 최종 결과는 [글자 조정 검증](2026-11-04-admin-workspaces/typography-validation.md)에 별도로 기록했다.

PR01의 공통 본문 delta 기본값은 0px이며 PR04가 2px를 활성화한다. 따라서 최종 시안은 네 PR을 모은 통합 브랜치의 화면으로 판정한다. 이번 범위에는 새 기능·조회·제어·폼 동작·레이아웃 개편을 추가하지 않는다. 글자 굵기와 터치 영역을 유지하며 글자 크기 때문에 생기는 줄바꿈을 확인한다.

검증은 같은 화면·뷰포트·상태의 이전 기준과 계산된 `font-size`를 대조한다. 메뉴 및 본문의 제목·표·목록·버튼·입력·수치는 정확히 +2 CSS px, 상태 주석은 차이 0px여야 한다. 사용자 지정 이미지의 `.read-stamp` 9px, 태그 10px, 인접 링크 11px와 큰 OPEN 상태값 31px는 유지 기준의 예다. 상단 상태 영역도 기존 크기를 유지한다. 실제 측정 결과와 재조회 이력은 별도 검증 기록을 따른다.

병합 예정 순서는 01 → 02 → 03 → 04이며 각 PR은 최신 main 기준의 필수 CI를 유지한다. 이번 후속 작업에서는 실제 병합이나 운영 배포를 실행하지 않는다.
