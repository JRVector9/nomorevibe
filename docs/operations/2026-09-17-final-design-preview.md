## 최종 리뷰에서 고친 항목

- 모바일에서 검색 입력이 숨겨지는 문제: 검색 버튼과 키보드 접근 추가, Radar에서 검색하면 Radar 경로 유지.
- 대시보드 필터 변경 후 이전 상세가 남는 문제: 현재 필터의 항목만 선택. 내 제품 이외의 피드백 제외.
- Agent 데이터를 사람 제출 경로에 전달하는 모의 전이: 거부하도록 추가.
- 업데이트 폼의 배포 링크: 저장하고 업데이트에서 안전한 HTTP(S) 링크만 표시.
- 초기 캡처에서 발견된 hydration 경고: Playwright의 기본 caret 숨김이 hydration 전에 입력 style을 바꾼 것이 원인. `caret: initial`로 촬영하며 콘솔 오류 감시를 추가해 0건 확인. React 경고를 숨기는 설정은 추가하지 않았다.

## 구현 범위와 다음 작업

**완성된 것은 문서 기반 디자인 미리보기와 개발 계획이다. 운영 기능 전체를 구현·배포한 상태가 아니다.**

예시 제품·45C 시작 예산·피드백은 디자인 fixture다. 실제 권한 부여·공개 발행·서버 검증·파일 업로드·예산 연결 슬롯 정산·메일 발송·청구·Agent 실행은 하지 않는다. 파일 선택은 이름/공개 범위만 저장하며 원본은 업로드하지 않는다. 인증·요금·Agent 화면에는 이 경계를 안내한다. 이미 로그인한 운영 세션과 운영 데이터를 사용하지 않는다.

후속 PR은 개발 계획의 M1(제품 상태) → M2(계정·Claim) → M3/M4(미션·장부) → M5(심사) → M6(개선·알림) 순서다. 증거 연동·유료 Sprint·Agent 실행은 이후 별도 단계다. 기존 시스템과 데이터 이관, 트랜잭션, 권한·감사 및 실제 운영 검증을 각 PR 완료 기준으로 명시했다.

이번 브랜치는 **main에 병합하거나 운영 서버에 배포하지 않았다**. 기존 작업 디렉터리의 ProductHero 변경, PT 자료, 기존 프로토타입과 이전 작업 문서를 보존했다.
