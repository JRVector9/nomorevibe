# 2차 심사 자동 fallback — 2026-09-17

기본 심사가 시간 초과·게이트웨이 장애·유효하지 않은 응답 등으로 실패하면 설정된 다른 모델이 같은 입력을 심사한다. 이번 운영 설정은 **Qwen3.8-27b / GPT-OSS-120b → Claude CLI Opus**다. abc-llm 경로와 분리된 CLI를 첫 대체 경로로 사용한다.

## 동작 및 안전장치

- 설정에 대체 모델을 순서대로 최대 2개까지 둘 수 있다. 현재 검증한 Opus 하나만 활성화한다.
- 실패 기록을 지우거나 모델명을 바꾸지 않는다. 실제 대체 모델의 별도 행을 만들고 `fallback_for_id`로 원래 표와 연결한다. 관리자 상세에 `대체 심사`와 실제 모델명을 표시한다.
- 대체 행은 다음 처리 회차에서 먼저 처리한다. 같은 후보의 1차 모델, 다른 기본 심사 모델, 이미 시도한 대체 모델은 제외한다. 후보 잠금과 트랜잭션으로 동시 실패의 중복 표를 막는다.
- 원래 호출부터 대체 호출까지 실패 횟수를 이어받아 총 3회에서 사람 확인으로 종료한다. 사용 가능한 대체 모델이 없으면 기존의 제한된 재시도 정책을 적용한다.
- 정상적인 승인·거부·보류는 재심사 대상이 아니다. 취소는 실패 횟수에 넣지 않는다. 입력 크기 초과는 같은 입력을 다른 모델에 보내지 않는다.
- 입력·근거·1차 판단·설정·작업 소유권을 재확인한다. 원래 모델 또는 대체 모델을 설정에서 제거하면 그 대체 의견도 현재 합의에서 제외한다.
- 자동 발행 정책이나 1차 Claude Sonnet 관찰 모드는 바꾸지 않는다.

## 실제 모델 검증

같은 14개 입력(과거 관리자 판정 12개 + 현재 실패 사례를 직접 확인한 2개)을 사용했다. 운영 DB의 판단은 바꾸지 않는 호출이었다.

| 대체 후보 | 완료 호출 | 유효 응답 | 기준 판정 일치 | 시간 |
|---|---:|---:|---:|---|
| Claude CLI Opus | 14 | 14 | 14 | 중앙 4.61초, 최대 9.93초 |
| qwen3-coder:30b | 12 | 4 | 4 | 8회 60초 시간 초과 |

Coder는 반복 시간 초과로 실험을 중단했다. 미완료 2개는 분모에 넣지 않았으며 운영 fallback에서도 제외했다. 소수의 의도적으로 고른 사례이므로 이 결과를 일반적인 정확도 100%로 해석하면 안 된다. 재현 입력은 앞선 `2026-09-17-second-review-fix` 평가와 동일하며, 응답/요약은 [평가 자료](evaluations/2026-09-17-second-review-fallback/summary.json)에 남겼다.
