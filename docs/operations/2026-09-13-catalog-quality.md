# 분류 품질·검색·스타 증감 개선 — 2026-09-13

## 요청과 변경

개인 연구 기록과 일회성 응답 설문은 독립 제품 목록에서 제외한다. 설문 제작 서비스, 연구 지원 도구, 설문을 입력으로 사용하는 추천 서비스는 유지한다. 수집 판정과 출판 직전의 공통 목적 검사에 반영하고 AI 심사 지침과 버전도 갱신했다. 기존 observe 정책은 유지한다.

전체 공개된 미소유 수집 항목을 보수적인 동일 기준으로 검사하고 실제 페이지를 확인했다. 다음 3개를 삭제 대신 감사 이력이 남는 공개 제외 상태로 전환했다(적용3, 변경 충돌0).

| 항목 | 확인한 목적 |
| --- | --- |
| Latent Coffee Research | 개인 커피 연구 일지 |
| Ontology, knowledge graph and AI research publications | 연구 출판물·문서 목록 |
| OTT | 석사학위논문 실험 설문 |

최신 페이지 제목·소개·본문을 우선 사용한다. 정리 계획에는 모든 판정 입력의 SHA256과 원본 수집 시각, 제품 수정 시각을 고정하며 적용 시 잠금 안에서 재검증한다. 이미 적용한3개도 최신 메타데이터로 재확인했다. 수정된 검사로 공개 목록을 다시 조회한 결과 추가 후보0개였다. 이는 명확한 패턴에 해당하는 추가 후보가 없다는 뜻이며 모든 비제품을 완벽하게 분류했다는 뜻은 아니다.

검색은 이름·소개·설명·GitHub 아이디·저장소를 검색하며 공백으로 구분한 모든 단어를 적용한다. SQL 와일드카드는 문자 그대로 취급한다. 상단 검색은 이전 카테고리·순위 필터를 초기화하고 결과를 첫 화면에 표시한다. 이전에는 일치 결과가 화면 아래1431px에 있었고 @아이디는 검색 대상이 아니었다. 첫 표시9개, 더 보기9개로 변경했다. 기존 홈 조회 상한100개는 유지한다.

기존 스타 수집은 항목별 하루1회 성공 갱신을 이미 수행하고 있었다(사전 검사6743개 중6686개가24시간 이내 수집). 이전 성공값과 그 시각을 보관하도록 확장해 현재값과 증감을 홈·인기 목록·상세에 표시한다. 실패 시 비교값을 이동하지 않고 저장소 변경 시 초기화한다. 과거 값을 추정하지 않으며 두 실제 관측값이 없으면 비교 수집 중으로 표시한다. 비교 시각은 한국 시간으로 제공한다.
