# 거부 큐의 500스타 제품 누락과 발행 24시간 증감

2026-09-21 운영 조회에서 거부 상태인 500스타 이상 후보 234건을 확인했다. 이전 392건 재심사 중 323건 발행 확인은 사실이지만, 모든 500스타 이상 거부 항목이 처리된 것은 아니었다.

## 원인과 조치

- 70건은 같은 URL의 제품이 이미 존재하는 중복 거부다. 제품의 repo_url만 대조하면 기존 항목을 놓치므로 원본 홈페이지 URL과 기존 제품 슬러그도 대조했다. 거부 화면에 중복 설명과 기존 제품 링크를 추가했다(슬러그가 기록된 경우).
- 설치형 예외가 배포 URL 없음·저장소 루트·일부 문서 URL에만 적용됐다. GitHub 릴리스, npm, SNS, 문서 제목, 접속 실패 홈페이지는 앞선 규칙에서 거부되어 설치형 심사를 받지 못했다. 500스타 이상 활성 원본 저장소는 홈페이지가 규칙을 통과하지 못해도 README를 통한 실제 소프트웨어 심사로 넘어간다.
- 판단·1차 입력·분류·발행·발행 잠금에서 같은 접근 방식 계산을 사용한다. 원본 URL을 바꾸지 않고 공개 제품의 접근 방식만 설치형으로 전환한다. 기존 홈페이지 URL의 중복·차단을 우회하지 않는다.
- 연구문서·설문, 보관·포크 제외 및 1·2차 심사·원본 변경 검증을 유지한다. 별 개수만으로 승인하지 않는다. 규칙 2026-09-21.2, 공유 심사 프롬프트 2026-09-21.3.
- 이전 관리자 거부는 기본 재심사에서 보호한다. 이번 사용자 요청 범위에서는 `--include-admin`으로 15건을 포함하고, 이전 결정·사유를 감사 이력에 남긴 뒤 자동 심사로 되돌린다.

## 발행 완료 표시

`발행 완료 12,345 (+160)` 형태로 최근 24시간의 발행 상태 순증감을 표시한다. 전일 발행량과의 비교가 아니다. 발행 상태로 들어오면 +1, 빠져나오거나 후보가 삭제되면 -1이며, 설명 수정은 세지 않는다. 툴팁에 진입·이탈 건수를 제공한다. DB 트리거가 기록하므로 수동 처리와 워커 발행 모두 집계한다. 새로고침 시 현재 시각의 이동 구간으로 계산한다.

마이그레이션 0042는 기존 발행 후보의 최종 상태 전환 시각으로 초기 이력을 만들고, 이후 변화는 트리거로 기록한다. 초기 적재와 트리거 설치 사이의 누락을 막기 위해 같은 트랜잭션에서 짧게 쓰기 잠금을 사용한다. 앱/DB 시계 차이로 방금 발행한 항목이 빠지지 않도록 DB 시각으로 조회한다.
