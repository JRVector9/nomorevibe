## 변경

- 검수: 활성 필터에 필요한 신선 membership만 주 목록 전에 조회한다. CSV도 같은 필요조건을 사용한다. 갈래 ID 배열의 반복 전체 복사를 제거했다.
- 닫힌 검수 필터/관리 패널은 서버 reader를 시작하지 않는다. 실제로 열 때 기존 query를 유지한 채 해당 패널을 읽는다. 같은 렌더의 판정 Promise는 공유한다.
- 프로젝트: 상세 section별 조회를 선택하고 이미 읽은 프로젝트를 재사용한다. 소개 번역·메모를 병렬로 읽는다. 헤더의 소유/충돌 표시와 기존 폼은 유지한다.
- 콘텐츠: 새 화면에서 사용하지 않는 랭킹 preview와 SNS 전역 summary를 생략한다. 기존 전체 reader의 기본 동작은 유지한다.
- 흐름: 변경 기록·진단 탭의 불필요 fan-out을 줄이고 개인 away와 고급 FlowBoard를 별도 Suspense slot으로 보낸다. 기존 단계·기간·순위 선택 state는 유지한다.
- LLM: 기본 상태판은 고급 차트용 완료 이력 표본을 읽지 않는다. full 기본 reader의 repeatable-read·50,000행 상한·미확인 규칙은 유지한다. bootstrap과 고급 조회를 실제 로딩 경계 안으로 옮겼다.
- 갱신: 실시간 흐름/LLM 15초, 검수 기본 30초, 이력·설정 등 60초로 목적을 구분한다. 탐색·수동·자동 읽기의 경합, redirect/중단 뒤 영구 busy, 열린 모든 dialog의 갱신을 막는다. 기본 검수 탭 표시는 서버의 human과 일치시킨다.

새 공유 캐시·DB 스키마·사용자 기능은 추가하지 않았다. 기존 15/30/60초 표시 캐시와 명령의 인증·ingress·CSRF·CAS·DR fence·원본 상태 재확인을 유지한다. 개인 away와 편집 판·원문을 공유 캐시에 넣지 않는다. 설정 snapshot/요청 선택 캐시는 새로운 무효화 계약이 필요하므로 이번 최소 변경에 추가하지 않았다.
