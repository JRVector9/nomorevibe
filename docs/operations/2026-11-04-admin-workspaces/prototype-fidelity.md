# 원본 HTML 시안의 실데이터 구현과 대조

기준 화면: http://gpu3090.tail02799e.ts.net:8788/final/index.html#/home

실제 구현: http://gpu3090.tail02799e.ts.net:8789/admin/flow

기준 소스는 최초 HTML 시안의 `index.html`, `styles.css`, `app.js`다. 시안의 화면 배치·영역 순서·카드·목록과 선택 상세를 Next 컴포넌트로 옮겼다. 공통 CSS는 `.admin-prototype` 범위에 옮겨 공개 화면 스타일과 분리했다. 데이터·처리는 실제 기존 서버 조회와 보호된 액션을 사용하며, 원본의 예제 프로젝트·난수/예시 그래프·상황 선택·타이머 기반 가상 처리는 가져오지 않았다.

앞선 메뉴 개편 기록과 구분되는 이번 검증의 기준은 **원본 시안의 페이지 구성을 실제 데이터로 재현했는가**다. 기존 화면을 그대로 새 메뉴 아래 펼치는 방식을 기본 화면에서 대체했다.

기존 고급 편집기·정책·복구 기능은 명확한 고급 링크나 접기로 보존했다. LLM 고급 화면은 `advanced=1`을 명시했을 때 렌더하여 기본 화면의 숨긴 구성 요소가 능동 probe나 중복 조회를 실행하지 않게 했다. 실제 설정·순위 SELECT snapshot은 읽기 전용 미리보기에서도 읽는다.

## 실제 데이터와 동작 경계

- 기존 운영 복제본을 조회한다. 예제 항목을 채우지 않으며, 빈 결과와 조회 실패·미집계를 구분한다.
- 단계별 모델 호출 수가 기존 집계에 없으면 `—`로 표시한다. 유효 잠금에서 읽은 잡 실행 수와 모델 장부의 실제 호출 수를 섞지 않는다.
- 공개 완료와 공개 후 검색·번역, 후보 수와 2차 표 수, 접수 대기와 미확정 요청을 구분한다. 공개 결과의 5분/24시간 수가 없으면 1시간 수를 비례 확대하지 않는다.
- 기존 수동 카테고리 지정·발행 검토 writer는 유지하며 `/admin/status?tab=manual`로 연결한다. 현재 원본 snapshot과 sourceHash는 해당 원래 화면에서 읽는다.
- 영속 보류 저장·요청함/SNS 전용 CSV 등 원본 시안에만 있고 대응 원본 writer/export가 없는 동작은 성공을 모사하지 않는다. ‘검토 유지’는 현재 상태를 바꾸지 않는다고 표시한다. 기존에 지원하는 CSV·처리·복구 경로는 유지한다.
- 소개 편집 등은 원래 writer가 허용하는 상태·원본 판에서만 실행한다. 저장하지 않은 입력, 원본 변경, 처리 판·CSRF·감사 기록의 계약을 유지한다.
- 미리보기는 읽기 전용이다. 운영 변경·모델 시험 호출·운영 배포를 실행하지 않았다. 스크린샷은 운영 정보가 포함되어 private 임시 폴더에만 보관한다.

## 대조 과정에서 수정한 문제

- 공개 홈의 동명 `.tabs`가 섞이는 pill 처리와 Tailwind 초기화에 따른 제목 굵기를 격리·복원했다.
- 프로젝트 상세의 브라우저 코드가 server schema barrel을 통해 `node:net`을 가져오던 경계를 browser-safe 상수 import로 바꿔 8탭을 실제 렌더했다.
- 검수 페이지 번호와 줄임표 React key 충돌을 분리했다. 요청 선택 상세에는 원래 writer별 판 key를 유지하고 바깥 선택 key도 명시했다.
- 품질·번역의 초기 요약 화면을 원본 4종 검사/5열·3요약/프로젝트 표 구성으로 교체했다.
- Next GET Form에서 submitter의 mode가 사라지던 것을 명시적 쿼리 링크로 바꿔 4모드의 실제 전환을 확인했다.
- 흐름 상세표에 빠졌던 공개 결과 행, 잘못된 번역 필터 링크, 선택 단계와 다른 큐로 보내던 링크, 사람 확인 탭의 합의 완료 제외를 수정했다.
- private 개발 프록시의 HMR 연결 종료 EPIPE를 처리해 탐색 중 미리보기가 중단되지 않게 했다.
