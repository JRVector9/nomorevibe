## 글자 크기 기준

일반 메뉴명·탭·제목·표 헤더·프로젝트명·목록·버튼·입력·숫자 지표는 변경 전 계산된 크기에서 정확히 +2 CSS px다. 브랜드·아바타·아이콘·본문 밖 상단 영역·접근성 건너뛰기 링크는 이 확대 범위에 포함하지 않는다.

상태 배지·관측 시각·자동 관측 표시·흐름의 짧은 상태/모델 주석·워커의 관측 주석·설정 적용 상태·현재 운영 상태 요약은 차이 0px로 유지한다. 상태 그룹 옆의 용량 링크와 큰 OPEN 상태값도 보존한다. 기록 표의 일반 날짜와 폼 설명문은 일반 본문으로 확대한다.

| 사용자 지정 상태 예 | 변경 전 | 변경 후 기준 |
| --- | --- | --- |
| 관측 시각 `.read-stamp` | 9px | 9px |
| OPEN 배지 `.tag` | 10px | 10px |
| 인접한 `용량·장비 →` 링크 | 11px | 11px |

상태값이 없는 요약 숫자는 일반 지표이므로 +2px다. 기존 프로젝트 이름은 실제 화면의 22px 기준에서 24px로 조정했다. 전역 비율 확대나 브라우저 확대는 사용하지 않았다.
