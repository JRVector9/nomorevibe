# 한국어 제품 소개 번역: GPT-OSS와 GPU Qwen

`product-tagline-ko`는 기존 text 역할과 잡 lease를 유지하며 전용 `korean-translation`
실행 줄에서 돈다. GPT와 Qwen은 서로 다른 제품 묶음을 맡고, 모델마다 동시에 한 번만
호출한다. 저장 전 현재 원문·공개 상태·잡 소유권과 기존 한국어 품질 검사를 적용한다.

## 요청 한도

운영 legacy 경로의 소개 입력 묶음 기준은 1,200자에서 3,600자로, 출력 한도는
`600 + 150 × 항목 수`에서 `1,800 + 450 × 항목 수`로 각각 3배 늘어난다.
한 묶음은 최대 8건이며 출력 한도는 1건 2,250토큰, 8건 5,400토큰이다.
소개 글자 수와 모델 입력 토큰 수는 다른 단위다. 모델 서버 전체 컨텍스트는 바꾸지 않는다.

엄격 용량 제어가 `open`이면 기존 native 계약의 1,200자·원래 출력 한도를 유지한다.
이때 Qwen 직접 호출과 추가 재검토는 열지 않는다. `draining` 등 다른 상태도 직접
호출을 허용하지 않는다. 사유 번역·검색 번역·다국어 제품 번역의 요청 형식은 유지한다.

## Qwen 연결과 제한 재검토

`KOREAN_TRANSLATION_QWEN_ENABLED=true`로 GPU3090의 고정 vLLM 모델
`qwen3.8-flash-next`를 사용한다. 번역 전용 프롬프트를 적용하고 응답 모델·종료 상태·
배열 개수와 각 소개의 품질을 검증한다. 실제 결과 모델을 한국어 소개 캐시에 저장한다.
운영 Qwen 요약 프롬프트는 수치의 최대 한도·자체 호스팅·베타 등의 범위를 보존한다.
원문에 `up to` 또는 `at most`가 붙은 백분율을 출력하면서 한도 표현을 지우면
`qualifier_lost`로 거절한다. 길이 때문에 수치 주장 전체를 생략하는 요약은 허용한다.

`KOREAN_TRANSLATION_QWEN_RECOVERY_ENABLED=true`도 설정하면 현재 원문이 일치하고,
일반 품질 한도 4회 또는 현재 홈의 한도 6회에 정확히 도달한 항목을 Qwen으로 제한
재검토한다. 재시도 시각이 지났고 총 시도 수가 10 미만이며 마지막 모델이 Qwen이
아닌 항목만 고른다. 한 틱에서 최대 8건이며 기존 실패 횟수는 초기화하지 않는다.
품질 실패는 기존 거절 횟수에 더하고, 네트워크 실패도 실제 Qwen 모델로 기록한다.
홈 포함 여부와 원문 변경은 기존 정책대로 다시 판단하므로 모델별 1회 내구성 원장을
추가한 것으로 해석하지 않는다.

두 플래그의 기본값은 `false`다. text 주·예비와 관리자 화면을 제공하는 두 웹 앱에
같은 값을 적용한다. 모델 연결을 끄면 새 Qwen 호출과 추가 재검토가 닫히며 기존
실패 기록과 검증된 번역은 유지된다. 관리자 상태의 즉시 처리 수에는 현재 가능한
제한 재검토가 포함되며, 품질 검사 중단과 재시도 예약을 따로 확인할 수 있다.
