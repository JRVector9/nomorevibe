왜 ‘미확인’인가요?

서비스와 저장소는 공개 정보로 확인했지만, 실제 운영자가 NoMoreVibe에서 소개 내용과 연락처를 확인하지 않았습니다.

표시 기준 보기
  • GitHub 계정과 저장소 관계는 공개 API로 확인
  • 실제 제작자 여부는 소유권 확인 전까지 단정하지 않음
  • 연락 버튼은 공개된 공식 경로만 표시
