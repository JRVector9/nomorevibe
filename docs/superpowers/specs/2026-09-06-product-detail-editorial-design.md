# 제품 상세 에디토리얼 디자인

## 목표

제품 상세 첫 화면에서 대표 이미지를 충분히 크게 보여주고, 제품이 무엇을 하는지와 정보의
출처 상태를 스크롤하기 전에 이해할 수 있게 한다. 사용자가 선택한 A 시안을 실제 데이터와
기존 증거 표시 규칙에 맞춰 적용한다.

## 레이아웃

- 데스크톱 히어로는 대표 화면 2/3, 제품 설명 1/3 비율의 비대칭 2열이다.
- 대표 화면은 첫 번째 내부 보관 이미지를 원본 비율로 표시한다. 이미지가 없으면 제품 아이콘과
  `아직 보관된 제품 화면이 없습니다` 상태를 같은 면적 안에 표시한다.
- 우측에는 제품명, 상태, 시즌 순위, 태그라인, 상세 설명, 카테고리·운영 단계·가동 상태,
  공유·방문 버튼을 둔다.
- 방문과 가동 지표는 히어로 바로 아래의 얇은 스트립으로 유지한다.
- 본문은 넓은 제품 이야기 열과 좁은 근거 열로 구성한다. 제품 이야기에는 구조화된 소개와
  업데이트를, 근거 열에는 근거 요약·객관적 정보·저장소·AI 제작 정보·갱신 상태를 둔다.
- 모바일은 히어로 이미지, 제품 설명, 지표, 상세 소개, 근거 정보, 업데이트 순으로 한 열에 쌓는다.

## 정보 원칙

- 수집된 `product.description`, 프로필, 저장소 관측값만 표시한다. 시안용 문구를 제품 사실로
  옮기지 않는다.
- 메이커 제공, 자동 감지, 공개 출처 확인 상태를 기존 `SourceBadge` 표현으로 계속 구분한다.
- 외부 이미지를 직접 요청하지 않고 `/api/media/` 내부 사본만 사용한다.
- 대표 이미지 아래에 크기와 사본 갱신일을 표시해 이미지 출처의 상태를 숨기지 않는다.

## 접근성·반응형

- 제목 계층과 기존 랜드마크를 유지하고 모든 조작 요소 높이는 44px 이상으로 둔다.
- 모든 본문 글자는 13px 이상, 텍스트 대비는 WCAG AA를 만족한다.
- 390px 화면에서 가로 스크롤이 생기지 않아야 한다.
- 대형 히어로는 서버 컴포넌트로 렌더링하고 공유·업데이트 필터만 기존 클라이언트 경계를 유지한다.
