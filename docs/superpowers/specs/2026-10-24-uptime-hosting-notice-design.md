# Uptime 호스팅 중단 안내의 보류 계약

실제 개발 표본 17건 중 결제 오류 2건은 현재 본문 전체가 `Payment required DEPLOYMENT_DISABLED`와 요청 추적 ID뿐인데도 모델이 영구 종료·자동 내림 후보로 제안했다. 인용과 경로는 유효해 기존 guard를 통과했다. 소개나 가격을 가진 제품 본문 또는 명시적 종료 안내와는 다르다.

승인된 설계는 complete page의 HTTP 402 결제 비활성 안내와 HTTP 503 배포 일시 중단 안내에만 전체 본문 일치 검사를 적용하는 것이다. 안내 뒤의 단일 요청 추적 ID는 선택적으로 허용한다. 다른 내용이 함께 있으면 이 알려진 안내 화면 규칙으로 판단하지 않는다. 해당 안내만 근거인 자동 내림 제안은 검증 오류로 보내 소비자의 사람 확인 큐에 남긴다.

프롬프트도 두 안내를 unclear·추가 근거/사람 확인으로 분류하도록 명시한다. HTTP 상태 전체 차단, 단어 하나로 종료 판단, 잘못된 응답 자동 수정, 인용 정규화, 새 provider 분류 프레임워크는 만들지 않는다. 실제 모델 추가 호출은 없다.
