# 추가 재점검 및 적용 — 2026-09-06

사용자의 재점검 요청에 따라 수집 워커, 자동 판정/발행, 공개 화면을 다시 확인하고 발견한 문제를 수정했다.
적용 대상은 로컬 localhost:3000과 개발 DB55434, 별도 evidence 워커다.

## 발견한 문제와 수정

- **예산 종료 시 저장소 건너뜀:** SHA 확보 전 종료가 원인 없는 실패로 기록되고 cursor가 전진했다.
  `budget_exhausted`로 구분하고 현재 수집 위치를 유지한다. 남은 deadline으로 요청 timeout도 제한한다.
- **실패한 재확인 결과 누락:** 이전 완료 스캔 뒤 private/404/timeout이 발생하면 실패 이력이 저장되지
  않을 수 있었다. 과거 관측은 보존하고 최신 실패를 기록해 자동 판정을 보류한다.
- **오래된 연결 정보 재사용:** 사이트 확인 시간이 오래됐거나 미래/잘못된 값이면 제품 관계를 확정하지
  않는다. 최근 스캔 실패와 사이트/스캔의 24시간 최신성을 판정과 발행 직전 모두 검사한다.
- **자동 판정 경합:** 원본을 읽은 뒤 관리자가 거부하거나 문서/설정이 변경돼도 자동 결과가 덮어썼다.
  잠금 안에서 읽었던 후보·문서·설정을 비교하고 변경됐으면 다음 틱에서 다시 읽는다. 관리자가
  명시적으로 `new` 상태로 요청한 재판정은 계속 지원한다.
- **미확인 값의 확정 표시:** 저장소 archive/fork 값이 없는데 활성으로, 연결 정보가 없는데 일부 연결로
  표시될 수 있었다. 미확인으로 표시하며 실제 단방향 연결은 방향을 구분한다.
- **초기 HTTP 실패의 온라인 표시:** 503 응답이 아직 장애 임계값 3회에 도달하지 않으면 온라인으로
  표시될 수 있었다. 마지막 HTTP 성공 여부를 따로 표시하고 기존 장애 임계값은 유지한다.
