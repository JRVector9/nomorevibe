# 기존 OpenCode CLI를 LLM 작업에 연결

상태: 로컬 구현과 코드 리뷰 후 커밋. 이번 작업에서는 푸시, 배포, 운영 DB 이전, 운영 모델 호출을 하지 않는다.

## 적용 범위

- 기존 AI 1·2차 검수 연결을 유지한다.
- 소개 생성, 번역, 검색 프로필·검증, 발행 분류, 사람 위임·갈림·보류 검수, 발행분 감사·추가 의견·화면 판별, LLM 보강에서 등록된 OpenCode 모델을 사용한다.
- 소개 검수와 감사 캠페인은 기존 CLI 장부 경계를 사용한다. 새 감사 캠페인은 선택한 OpenCode 연결·모델·추론 강도를 시작 시 고정한다. 실행 중 모델 변경으로 이전 연결을 잘못 재사용하지 않는다.
- 숫자 벡터·rerank 응답이 필요한 검색 API와 Grok 로그인 유지의 역할은 유지한다. 용량 제어를 거치지 않는 옛 한국어 직접 호출에는 CLI를 추가하지 않으며, 한국어 소개 번역은 기존 용량 제어 작업에서 설정한다.
- 기존 로그인과 설치를 재사용한다. 설치·로그인·CLI 버전 고정·다른 모델로의 임의 대체를 추가하지 않는다.

## 실행과 제한

텍스트·발행·로컬 검수는 기존 요청 및 결과 검증을 재사용하고, 등록된 CLI 호스트가 요청을 실제 프로세스로 실행한다. 계약에는 연결 ID와 추론 강도를 고정한다. 장비 ID를 공유하여 단계마다 동시 실행 한도를 새로 만들지 않는다. 같은 모델의 다른 추론 강도는 별도 계약으로 보관하되 같은 장비 한도를 따른다.

호스트는 primary 장부의 실제 dispatch·계약·입력 해시·모델·연결 인증을 확인하고, 재시작 후에도 같은 요청을 다시 실행하지 않도록 일회 실행 표식을 남긴다. 실제 프로세스 종료와 최종 응답을 확인한 서명 증거를 클라이언트가 검증한 뒤에만 업무에 응답을 전달한다. 종료를 확인하지 못한 실패는 기존 미확정 처리로 남기며, 네트워크 종료를 모델 종료로 간주하지 않는다.

화면 판별은 실제 카탈로그에서 이미지 지원이 확인된 모델과 CLI의 파일 첨부 기능을 함께 요구한다. 문맥 크기·vision 정보가 없는 이전 연결은 모델 목록을 다시 조회한 뒤 저장한다. CLI 메타데이터 조회는 편집 화면과 해당 작업에서 명시적으로 CLI를 선택한 경로에 한정하며 일반 흐름 페이지 로딩에는 추가하지 않는다. 다른 작업의 CLI 연결 상태가 API 작업의 시작을 막지 않도록 단계 범위도 해당 작업으로 제한한다.

## 코드 리뷰 반영

- 일반 보강과 감사 보강의 모델 범위 선택을 실제 작업 종류 기준으로 수정했다.
- API에서 CLI로 변경할 때 남아 있는 API 키가 CLI 실행을 막지 않도록, primary 장부에서 확인한 CLI 인증으로 교체한다. 다른 CLI 연결의 인증 불일치는 거절한다.
- 발행 분류의 클라이언트 선택 목록에서도 OpenCode를 허용한다.
- HTTP 주소는 Host 헤더로 재구성하지 않고 실제 계약과 같은 원래 주소를 검증하여 HTTPS 연결도 처리한다.
- 감사 모델을 변경했을 때 이전 캠페인의 CLI 연결을 다른 모델에 재사용하지 않는다.

## 이후 반영 시 필요한 항목

`0168_opencode_task_cli.sql`은 소개·감사 OpenCode 장부 검사 분기와 감사 캠페인 연결 기록 열을 추가한다. 기존 검사 규칙은 유지한다. 이번 작업에서는 적용하지 않는다. 이후 승인된 배포에서 DB 이전 및 웹·소비자와 M3 기존 CLI 브리지의 새 코드를 함께 반영해야 한다. 웹만 갱신하면 새 CLI 실행 경로는 완성되지 않는다.

검증 결과는 커밋 시 최종 확인한 정적 검사 및 번들 검사만 기록하며, 수동 업무 테스트와 실제 모델 추론 성공을 대신하지 않는다.

## 최종 검증

- Next route type 생성 및 TypeScript 정적 검사 통과.
- 변경된 TypeScript 64개 파일 ESLint 및 `git diff --check` 통과.
- 웹의 webpack compile 모드 빌드 통과. standalone 추적 파일 27건 경고가 있어 이 로컬 산출물은 배포용 검증 결과로 취급하지 않는다.
- CLI 호스트 번들 생성과 네트워크·프로세스 실행을 차단한 import 검사 통과.
- 전체 unit·DB 테스트와 운영 모델 추론 테스트는 실행하지 않았다.
