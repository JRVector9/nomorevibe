# 모델·작업 통합 시안 및 검수 기록

- `index.html`: 승인된 독립 HTML 시안. 구현 검수 중 원본을 수정하지 않았다.
- `validation.json`: 독립 HTML 시안의 초기 Chromium 검증 결과. 운영·전체 테스트 결과와 구분한다.
- `previews/`: 초기 시안 캡처.
- `report.html` + `report-data.json`: 최종 검수 및 배포 상태 기록.
- `report-assets/`: 승인 시안, 실제 React 구현, 실제 운영 화면의 비교 캡처.

보고서의 운영 상태는 `report-data.json`의 `updatedAt` 시점 기록이다. 자동 갱신은 이 JSON 파일을 다시 읽는 동작이며, 운영 API를 직접 조회하지 않는다. 6시간 관측 대기는 해당 기록 시점의 미완료 상태로 유지했다.

구현 PR #929·#930·#931은 병합됐으며, 운영 반영 버전은 `5b058e8378ed7d6aa49531b83e6c242b8b9beb53`이다. 실데이터와 기존 공통 화면 프레임, 실제 용량 경고·지원 한도 등 시안과의 차이는 보고서에 명시한다. 모든 화면의 픽셀 일치를 주장하지 않는다.

정적 HTTP 서버에서 이 폴더를 열면 된다. 실행 중인 검수 링크:

- 시안: http://gpu3090.tail02799e.ts.net:8788/
- 보고서: http://gpu3090.tail02799e.ts.net:8788/report.html

로그인 정보, 키, 원본 운영 설정, 비공개 배포 계획 및 요청 본문은 포함하지 않는다.
