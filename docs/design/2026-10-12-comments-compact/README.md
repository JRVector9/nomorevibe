# 상세페이지 댓글 UI 시안

2026-10-12. 사용자 요청에 따른 디자인 제안이며 운영 UI에 적용하지 않았다.

전체 흐름은 [scenario.html](scenario.html)에서 확인한다. 상세페이지 전체를 시작점으로 댓글 위치, 로그인, 외부 GitHub 인증 개념도, 작성, 접수 결과를 이어서 눌러볼 수 있다. 상단 단계·조건 버튼은 시안 검토용이며 운영 사이트에 추가하는 UI가 아니다. ManimGX의 댓글 없음·GitHub 수신 미연결 상태가 기본이며 예시 댓글이 있는 상태도 선택할 수 있다. 모든 인증·댓글·전송 동작은 브라우저 안에서 재현하며 실제 서버에 요청하지 않는다.

처음 만든 [index.html](index.html)은 기본 화면과 작성 화면을 나란히 비교하는 시안이다. 실제로 이 두 화면이 나란히 표시되는 것은 아니다.

## 화면이 나오는 시점

| 상황 | 화면 |
| --- | --- |
| 프로젝트 상세페이지 방문 | 기존 프로젝트 정보·README·업데이트. 그 아래에 댓글 영역이 있음. |
| 댓글 영역까지 스크롤 | 댓글 목록과 48px 한 줄 작성 진입. 로그인 없이 읽을 수 있음. |
| 비로그인 상태로 작성 클릭 | 로그인 화면 → GitHub 인증 → 동일 프로젝트 댓글 위치로 복귀. |
| 로그인 상태로 작성 클릭 | 그 자리에서 작성창 펼침. 별도 댓글 작성 페이지로 이동하지 않음. |
| 정상 접수·공개 완료 | 작성창 접힘, 접수 안내와 공개된 최신 댓글 표시. |
| 검토 필요로 접수 | 내 댓글에 검토 중 상태 표시. 공개 목록·개수에는 포함하지 않음. |
| 접수 결과 확인 실패 | 내용과 작성창을 유지하며 다시 등록 안내. |

현재 서버는 동일 본문 반복 또는 제목·본문의 HTTP(S) 링크 4개 이상일 때 검토 상태로 초기 접수한다. 그 외는 초기 공개 상태로 접수한다. 시안에서는 상단 등록 결과 선택으로 두 경우와 실패를 재현한다. 로그인 후 작성창 자동 펼침은 이번 UI 제안이며 아직 운영에 적용하지 않았다. 현재 GitHub 로그인의 스타 권한 동의도 시안에 반영했다. 댓글 전용으로 인증 권한을 분리하는 변경은 수행하지 않았다.

## 제안

- 기존 흰색 배경·빨간색 강조와 상세페이지 구조를 유지한다.
- 작성 폼과 목록을 하나의 `댓글` 영역으로 묶는다. 기본 작성 진입은 높이 약 48px의 한 줄이다.
- 클릭하면 같은 위치에서 본문 입력, 질문·오류·제안 분류, 공개 동의, 등록 버튼이 펼쳐진다.
- 제목은 따로 입력하지 않는다. 실제 구현 시 기존 API의 필수 제목 계약을 유지하면서 본문 첫 줄로 제목을 만들 수 있는지 검토한다.
- 목록은 처음 3개를 보여주고 긴 본문은 2줄 미리보기와 더보기로 펼친다. 전체·내 댓글 필터를 유지하며 검토 중인 내 글은 공개 목록과 구분한다.
- GitHub 전송은 제작자가 연결한 프로젝트에서만 작성 중 선택할 수 있게 접는다. 앱 봇 명의로 공개 이슈를 만드는 현재 전달 방식과 별도 동의는 유지한다. ManimGX의 현재 미연결 상태에서는 전송 옵션을 숨긴다.
- 제작자 수신 설정은 작은 메뉴 안으로 옮긴다. 답글·좋아요 등 새로운 기능은 추가하지 않는다.

## 직접 확인한 범위

Chrome에서 기본 비교 화면, 한 줄 입력 클릭 후 작성창 펼침, 취소 후 접힘, 댓글 없는 화면, 모바일 시안 배치를 확인했다. 작성창이 비어 있고 동의하지 않은 상태에서 등록 버튼이 비활성화되는 것도 확인했다. 운영 댓글 등록이나 GitHub 이슈 전송은 수행하지 않았다. 자동 테스트·빌드·제품 코드 수정·배포는 하지 않았다.

전체 시나리오에서는 상세페이지 전체 screenshot, 비로그인 작성 → 로그인 동의 → 외부 인증 개념도 → 인증 후 동일 페이지의 빈 작성창 복귀를 실제로 눌러 확인했다. 예시 본문 입력 상태와 공개 동의 후 등록을 눌러 접수 중 → 공개 완료·댓글 수1 상태를 확인했다. 검토 중에서는 내 댓글에만 글이 표시되고 전체 목록·공개 수0으로 구분되는 것도 확인했다. 실패 단계에서는 본문이 보존되는 AX와 모바일 작성 화면 screenshot을 확인했고, 모바일 하단 버튼 줄바꿈을 CSS로 보완했다. 이것은 로컬 시안의 동작 확인이며 실제 인증·접수·전송 성공 검증이 아니다.


전체 시나리오 주소: `http://127.0.0.1:8767/scenario.html`. 이전 비교 시안 주소: `http://127.0.0.1:8767/`. 현재 작업에서 이미 서버를 시작했으므로 사용 중인 포트에 중복 실행하지 않는다. HTML 파일 자체를 열어도 작동한다.
