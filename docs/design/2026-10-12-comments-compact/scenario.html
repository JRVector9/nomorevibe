README

ManimGX

Python으로 장면을 작성하고 Rust와 GPU로 애니메이션을 렌더링하는 프로젝트입니다.

Get started

pip install manimgx

설치와 기본 예제, 렌더링 옵션은 프로젝트 문서에서 확인할 수 있습니다.

From Python to MP4

import manimgx as m

class Hello3D(m.ThreeDScene):
    def construct(self):
        cube = m.Cube(side_length=3)
        self.play(m.Create(cube))
        self.wait(4)
